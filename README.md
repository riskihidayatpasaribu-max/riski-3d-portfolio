# Riski Hidayat Pasaribu - 3D Portfolio

Template web portofolio multi-halaman untuk karya 3D Modeling, Instrumentation, Electronics Project Visualization, dan House Design Visualization.

## Struktur File

- `index.html` - Halaman utama
- `portfolio.html` - Halaman portfolio
- `about.html` - Halaman profil
- `contact.html` - Halaman kontak
- `style.css` - Desain/tampilan web
- `script.js` - Menu mobile dan filter portfolio
- `assets/images/` - Folder gambar render karya

## Cara Mengganti Kontak

Buka `contact.html`, lalu ganti bagian berikut:

- `emailkamu@example.com`
- `@username_instagram`
- `linkedin.com/in/username`
- `github.com/username`

## Cara Mengganti Karya Portfolio

Buka `portfolio.html`, lalu edit bagian judul, kategori, tahun, dan deskripsi pada setiap `project-card`.

## Cara Upload ke GitHub Pages

1. Buat repository baru di GitHub.
2. Upload semua file dan folder dari template ini.
3. Buka Settings > Pages.
4. Pada Source, pilih branch `main` dan folder `/root`.
5. Klik Save.
